# PrestaShop The Courier Guy Delivery

A PrestaShop 8+ shipping module by **Kaziara Solutions** that keeps checkout compact by exposing one **The Courier Guy** carrier with selectable service tiers.

## ⬇️ Download

### [Download latest version (ZIP)](https://github.com/BaloyiTK/Prestashop-The-Courier-Guy/archive/refs/heads/main.zip)

Current release: **v1.0.0**

> After downloading, extract the repository archive and upload/re-zip the **`courierguydelivery`** folder for PrestaShop.

## Features

- One The Courier Guy carrier option in checkout
- Service-tier dropdown with fixed starting rates
- Domestic services for South African addresses
- International Express for international addresses
- Required destination PUDO locker for Locker-to-Locker
- Server-side delivery-step validation
- Selected service and locker stored against the order
- Order confirmation and admin order view display the selected service
- Safe uninstall cleanup

## Included services

| Service | Estimated delivery | Starting rate |
| --- | --- | ---: |
| PUDO Locker-to-Locker | 1–3 business days | R60 |
| Economy Road Freight | 2–4 business days | R95 |
| PUDO Locker-to-Door | 1–3 business days | R99 |
| Overnight Express | Next business day by 17:00 | R125 |
| Same-Day Metro | Same day when booked before 11:00 | R140 |
| International Express | 3–7 business days | R450 |

## Pricing note

Rates in this version are fixed starting/base prices supplied for the module. Actual courier charges can vary by parcel size, weight, route, surcharges and current Courier Guy pricing. This version does not call a live Courier Guy API.
